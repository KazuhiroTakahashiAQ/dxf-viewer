# DXF Viewer

ブラウザだけで動作する、DXF ファイル調査用のビューアです。読み込んだ図面は端末の外に送信されません（サーバー側の処理はありません）。

公開 URL: https://kazuhirotakahashiaq.github.io/dxf-viewer/

特定の用途に寄せず、「この DXF に何がどう書かれているか」を調べることを目的にしています。編集機能はありません。

## 主な機能

### 読み込み
- ASCII DXF / Binary DXF（R12〜R2018 以降）。全グループコードを行番号付きで保持し、未知のエンティティやコードも生データで確認できます。
- 文字コードの自動判定（BOM → `$ACADVER` → UTF-8 → `$DWGCODEPAGE` → Shift_JIS / EUC の推定）と手動切り替え。`\U+XXXX`・`\M+nXXXX` のエスケープ、`%%c` などの特殊コード、MTEXT の書式コードに対応します。
- 複数ファイルをタブで開けます。同じ内容のファイルは既存のタブに切り替わります。

### 表示
- 線・円弧・ポリライン（バルジ・幅付き）・楕円・スプライン・ハッチ（パターン・グラデーション）・寸法・引出線・マルチ引出線・表・MLINE・画像枠・ワイプアウトなど、DXF の主要なエンティティを描画します。ACIS 立体は枠と情報のみです（[対応状況](docs/coverage.md)）。
- ブロック参照（ネスト・MINSERT・属性・動的ブロック・XCLIP）。展開数に上限があり、巨大な図面でもブラウザが止まりません。
- レイアウト（ペーパー空間）とビューポート（ビューポート別のレイヤーフリーズ、非矩形クリップ）。
- 座標が 6〜8 桁ある図面（測量図など）でも、拡大時に図形が揺れたり潰れたりしないよう、タイルごとの局所原点で描画します。
- ビューの回転（90° 単位・角度指定・選択要素に合わせる・図面のビューツイスト）と左右・上下反転。座標表示は常にワールド座標（WCS）です。
- グリッド、ワールド座標軸、スケールバー、表示の戻る／進む、名前付きビュー（VIEW テーブル）、ビューの保存。
- 表示オプション: 背景色、線幅・線種・塗り・文字の表示切替、モノクロ、X 線（半透明表示）、OFF / 凍結レイヤーの淡色表示、外接枠・挿入点・制御点の表示、UI のライト／ダーク切替。
- 展開予算を超えたブロック参照は枠で表示し、右クリックから個別に展開できます（極端に大きいものは拒否します）。

### 調査
- **レイヤー**: 表示／凍結の切り替え、件数、AutoCAD のレイヤー状態（LAYERSTATE）の適用、レイヤー状態の保存。
- **ブロック**: 定義・参照数・未使用・プレビュー・単体表示。**構造**: 空間 → エンティティ → ブロック内部のツリー。
- **プロパティ**: 型ごとの値、算出値（長さ・面積・範囲など）、テキストの生データ／デコード後／プレーン、XDATA、拡張辞書、生グループコード表。ハンドルはリンクとして辿れます。複数選択時は型・レイヤー別の件数と共通の値を表示します。
- **選択**: クリック・窓選択・交差選択、類似選択、選択の反転、非表示・分離表示。ステータスバーには最後にクリックした点からの相対座標と距離を表示します。
- **絞り込み**: レイヤー・型・ブロック・色などのファセットと、AND / OR / NOT を入れ子にした条件（任意のグループコード `gc[8]`、XDATA、属性、計測値などを含む）。領域（表示範囲・矩形・多角形）でも絞り込めます。結果は一覧・強調・選択のいずれかで表示し、CSV / JSON に出力できます。
- **検索**: テキスト・ハンドル・レイヤー名・ブロック名を、現在のタブまたは開いている全タブから検索します。
- **計測**: 距離・経路長・面積・角度・エンティティの半径／長さ／面積・座標。端点・中点・中心・四半円点・交点・挿入点・近接点にスナップします。
- **ドキュメント**: バージョン・文字コードの判定根拠・生成アプリケーションの推定（根拠付き）・ヘッダー変数（説明付き）・テーブル・CLASSES・OBJECTS（辞書ツリー）・任意ハンドルのレコード表示・プレビュー画像・統計・描画カバレッジ。
- **Raw**: ファイル全体のタグを行番号付きで表示し、行ジャンプ・値の検索・該当エンティティへの移動ができます。
- **エクスポート**: PNG / SVG（現在の表示またはレイアウト全体）、レイヤー・ブロック・エンティティ型の CSV、選択要素やドキュメント概要の JSON。

### フォント
- 図面が参照するフォントを、端末にあればそのまま使い、無ければ同梱の代替フォント（日本語と英語）で表示します。
  - ＭＳ ゴシック / 明朝 → BIZ UD ゴシック / 明朝（文字幅互換）、メイリオ・游ゴシック → Noto Sans JP、Arial → Arimo、Times New Roman → Tinos など。
  - SHX フォントは Hershey のストロークフォントで代替し、日本語のビッグフォントは全角の正方セルに合わせて描画します。
- 手持ちの TTF / OTF / SHX をドラッグ＆ドロップで登録できます（このブラウザ内に保存）。フォントパネルで解決結果の確認と、代替先・幅・高さ倍率の変更ができます。

## 使い方

- 「開く」またはファイルのドラッグ＆ドロップで DXF を開きます。最初の画面からサンプル図面（`public/samples/`）を開くこともできます。
- 左・下・右のパネルは開閉とリサイズができます。フォーカスモード（`Ctrl+Shift+F`）ではステータスバー以外を隠します。
- ボタンやパネルのタブにマウスを合わせると、名前・説明・ショートカットがツールチップで表示されます。`?` キー（または `F1`、ツールバーの「?」）で、操作方法とパネルの一覧をまとめたヘルプを開きます。ヘルプからパネルを直接開けます。
- 要素の非表示・分離表示、「一致のみ表示」の絞り込み、ブロック定義だけの表示、ビューの回転・反転をしているときは、図面の上部にその状態が表示され、ボタン 1 つで元に戻せます。
- UI は日本語と英語に対応しています。既定ではブラウザの言語設定に従い、設定メニューの「言語」で切り替えられます。プロパティ名・グループコードの意味・ヘッダー変数の説明・診断メッセージも翻訳します（図面内の名前や文字列はそのまま表示します）。

| 操作 | キー・マウス |
| --- | --- |
| 全体表示 | `F` / `Home` / ホイールボタンのダブルクリック |
| 拡大・縮小 | ホイール / `+` / `-` / ピンチ |
| パン | 中ボタンドラッグ / `Space`＋ドラッグ / 2 本指スクロール |
| 選択 | クリック（重なりは繰り返しクリックで切り替え）、左→右ドラッグで窓選択、右→左で交差選択、`Shift` で追加、`Ctrl`/`⌘` で切り替え、`Ctrl+A` で全選択 |
| 計測ツール | `M` |
| 表示の戻る／進む | `Alt+←` / `Alt+→` |
| パネルの開閉 | `Alt+1`（左）/ `Alt+2`（下）/ `Alt+3`（右） |
| 解除 | `Esc` |
| ヘルプ | `?` / `F1` |

### 絞り込み条件の共有

絞り込みパネルのリンクボタンで、条件を URL（`#filter=…`）にしてコピーできます。リンクを開いても条件は自動では適用されず、内容を確認して「Load into editor」を押したときだけ読み込まれます。図面そのものは URL に含まれません。

### URL から開く

`?url=https://…/drawing.dxf` を付けて開くと、取得前に URL を表示して確認を求めます。取得はブラウザから相手のサーバーへ直接行われるため、相手側が CORS を許可している必要があります。

## プライバシーとセキュリティ

- 図面の解析と描画はすべてブラウザ内（Web Worker）で行います。外部への送信や外部 CDN の利用はありません（フォントも自己ホスト）。
- 「最近開いたファイル」は既定ではファイル名・サイズ・日時・内容のハッシュだけを記録します（Chromium ではファイルへの参照も保存します。中身は保存しません）。設定で「図面もこのブラウザに保存」を有効にした場合のみ、図面本体を IndexedDB に保存します。共有 PC では有効にしないでください。また、`kazuhirotakahashiaq.github.io` 配下の他のページとは保存領域（オリジン）が共通です。
- DXF 由来の文字列は常にテキストとして扱い、コードとして評価しません（`eval` や HTML への直接挿入は使いません）。本番ビルドは `unsafe-eval` やインラインスクリプトを許可しない CSP を設定しています。
- 共有リンクの条件は形式を検証したうえで、確認後にだけ読み込みます。入れ子の量指定子を含む正規表現など、処理が極端に重くなりうるパターンは評価しません。
- CSV 出力では `=` `+` `-` `@` で始まるセルを無害化し、SVG 出力では文字列を XML エスケープします。

## オフライン・インストール（PWA）

- 一度開いたあとはオフラインでも起動します。代替フォントは必要な部分だけを都度取得してキャッシュします。
- 設定メニューの「Download substitute fonts for offline use…」で、ファミリーごとの容量とブラウザの空き容量を確認してから、フォント一式を事前に取得できます（日本語ファミリーは 1 つあたり約 5〜8 MB）。
- インストールしたアプリ（Chromium）では、`.dxf` ファイルを関連付けて直接開けます。
- 新しい版が公開されると、再読み込みを促す通知が表示されます。

## 開発

```sh
npm ci
npm run dev        # 開発サーバー（http://localhost:5173/）
npm run typecheck  # 型チェック（UI・Worker・ツール・テスト）
npm test           # ユニットテスト（Vitest）
npm run build      # 本番ビルド（dist/）。代替フォントは @fontsource から public/fonts/ に生成されます
```

`main` ブランチへの push で GitHub Actions が型チェック・テスト・ビルドを行い、GitHub Pages にデプロイします。

### サンプルと参照レンダリング

サンプル DXF は [ezdxf](https://ezdxf.mozman.at/) で生成します（Python の環境は [uv](https://docs.astral.sh/uv/) で管理）。

```sh
cd tools/samples
uv run python generate.py          # public/samples/*.dxf と tests/fixtures/samples-manifest.json
uv run python generate.py --perf   # 性能確認用の大きなファイル（コミットしません）
```

ブラウザでの表示確認には、ローカルの Google Chrome をヘッドレスで操作するスクリプトを使います（開発サーバーを起動しておきます）。

```sh
node tools/e2e/shot.ts --file public/samples/basic_entities.dxf --out shot.png
node tools/e2e/perf.ts tests/real/.cache/perf/perf_498436.dxf   # 性能計測
node tools/e2e/ui.ts [--locale en-US]   # 言語・ツールチップ・ヘルプ・状態表示などの操作確認（スクリーンショットは tools/e2e/out/）
```

### 実ファイルコーパスと参照レンダリング

```sh
node tools/corpus/fetch.ts        # tests/real/corpus.json の公開 DXF を tests/real/.cache/ に取得（SHA-256 を検証）
npm test                          # 取得済みなら実ファイルの不変条件テストも実行
sh tools/reference/render.sh public/samples/*.dxf   # ezdxf・LibreCAD・このビューアの比較画像（macOS）
```

取得したファイルと比較画像はリポジトリに含めません。結果の要約は [docs/coverage.md](docs/coverage.md) にあります。

### テストの考え方

自己循環（同じライブラリで作ったデータを同じライブラリの結果と比べるだけ）にならないよう、次の 4 層で確認しています。

1. 仕様と手計算に基づくユニットテスト（OCS、バルジ、楕円、スプライン、MTEXT 書式、文字コード判定、計測値、絞り込み条件の総当たり比較など）
2. ezdxf で生成したサンプルの読み込み（件数・文字列の一致）
3. 独立した実装（ezdxf の描画アドオン、LibreCAD の `dxf2pdf`）との描画比較
4. Web で公開されている実際の CAD 出力ファイルでの不変条件チェック

## 既知の制限

- 表示は XY 平面（平面図）のみです。3D のビュー方向や ACIS 立体の形状描画には対応していません。
- DWG は読めません。外部参照（XREF）は枠のみ表示します。
- 印刷スタイル（CTB/STB）は適用しません。複雑線種の文字・図形要素は破線パターンで近似します。
- 画像（IMAGE）は、画像ファイルを別途ドロップしない限り枠とファイル名のみ表示します。
